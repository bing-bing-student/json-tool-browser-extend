## 示例与重拍步骤

编辑器字号设为 14，缩进设为 4 个空格；使用生产构建中的原始编辑器、设置和菜单。仅本地截图预览页面放大显示，未修改插件运行代码或 ZIP。采用两倍尺寸采集，再缩小导出商店要求的尺寸。

1. 格式化：`builtin-format-input.json5` 逐字取自 `src/components/utils/firstUseSampleJson.ts` 的 `FIRST_USE_SAMPLE_JSON_ZH`，未删减或改写示例内容。粘贴到左侧，关闭 JSON 语法诊断并点击“格式化”，滚回顶部。该示例含 JSON5 与工具扩展语法，关闭诊断是截图时的实际设置；完整输入保留 155 行，输出 130 行。
2. Diff：进入“对比”，左侧载入 `diff-before.json`，右侧载入 `diff-after.json`，两侧滚回顶部。示例中的客户、订单和物流编号均为虚构演示数据；同一长订单号在两侧保持一致。
3. 设置：返回普通编辑器，打开齿轮，展开“格式化设置”，保留其他设置分组标题与弹窗关闭按钮。
4. 右键菜单：左侧载入 `array-dedupe-input.json`，右键执行“数组去重”，再打开右键菜单截图。结果与 `array-dedupe-result.json` 一致，保留各对象第一次出现的顺序。
5. 深色主题：关闭右键菜单，点击状态栏主题按钮，截图展示同一组输入和去重结果。

示例仅用于重拍与验证，不随扩展安装包发布。仅更新截图和发布文档无需重新构建插件。后台上传这五张 PNG 后，保存商店资料即可；本地文件更新不会自动替换商店后台的图片。

参考：[Chrome 商店图片要求](https://developer.chrome.com/docs/webstore/images)。
