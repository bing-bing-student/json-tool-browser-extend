## 首次上传的操作顺序

1. 在项目根目录运行 `npm run verify-package`。如果失败，先运行 `npm run package` 再验证。
2. 在开发者后台的“内容”页点击“上传新内容”，选择 `release/json-tool-extension-1.0.0.zip`。输出目录中提供了同一份安装包副本。
3. 完成下列商店资料、隐私权实践和分发设置，上传 `assets/` 内图片。
4. 将 `privacy-policy.html` 放到可公开访问、无需登录的 HTTPS 页面，确认实际 URL 能正常打开，再填进后台隐私政策字段。请以实际部署和打开结果为准。
5. 确认账号的邮箱验证、两步验证与 Trader／Non-Trader 声明已完成，且符合实际情况。
6. 首次发布建议选择“审核通过后手动发布”，核对资料后再正式发布。

## 详细介绍：可直接复制

```text
JSON 工具箱，把常用的数据处理工具装进浏览器。

整理接口响应、检查配置、比对数据变化，都可以在同一个工作区完成。点击扩展图标，打开双栏编辑器，粘贴文本或拖入文件即可开始。免费、无需注册，断网也能使用。

✨ 核心亮点

• 长数字原样保留
格式化时保留长整数、高精度小数和末尾零，方便核对订单号、雪花 ID 和精确数值。

• 复杂结构更好浏览
按层级展开与折叠，折叠后显示对象键数和数组元素数，不必反复展开就能了解数据规模。双栏布局便于同时查看原始内容与处理结果。

• 常用操作就在手边
双击选中完整字符串，在预览区双击还可自动复制。右键复制字段路径，或对选中的内容进行局部处理，让取值和编辑更顺手。

🛠️ 常用功能

格式化与错误定位
支持带注释、单引号和尾逗号的常见输入，可调整缩进和数组排版。开启语法校验后，错误以红色波浪线提示，并可跳转到对应位置。

双栏差异对比
并排查看两份内容，通过行级与行内高亮定位变化，适合核对接口返回结果、配置修改和测试数据。

数组与文本整理
对数组排序、去重或按字段取值；也可清理文本中的空行、每行首尾空格，批量添加或移除前后缀，把零散日志和列表整理成可用数据。

转义、编码与格式转换
支持转义与去转义，可选择还原编码字符或保留原始写法。选中字符串后，通过右键完成 Base64 或 URL 编解码。还可转换数据格式或生成类型定义，方便在其他工具中继续使用。

字段脱敏与本地存档
按字段路径和规则遮盖敏感内容，便于准备调试示例。结果可复制、下载或保存为本地存档，方便再次打开和处理。

🔒 本地运行与隐私

编辑器和处理功能随扩展提供，所有数据处理均在当前浏览器内完成，不向开发者或第三方上传输入内容、文件和存档，不读取其他网页或浏览历史。

无广告，无需账号。设置和存档保存在本机，重要内容可自行导出备份。

🎨 按你的习惯使用

支持明暗主题和中英文切换，可调整字号、自动换行与同步滚动，配合查找、替换和常用编辑快捷键，适应不同的阅读与调试习惯。

安装后点击扩展图标，让下一次接口调试从一份清晰、可读的数据开始。

使用要求：桌面 Chrome 120 及以上版本，浏览器窗口宽度至少 901 像素。
```

## 如何确认安装包是最新的

`npm run package` 先构建当前源码，再生成 ZIP。ZIP 内的 `build-info.json` 记录 UTC 构建时间、Git 提交、是否含未提交修改及运行源码指纹；`release/` 同时生成 `.build-info.json` 与 `.zip.sha256`。

`npm run verify-package` 会核对当前版本与名称、源码和锁定文件的 SHA-256，以及 ZIP 的完整性。源码变更或 ZIP 被替换后会失败。文档与商店图片不影响运行，不纳入源码指纹。校验值用于核对本地构建，不代替 Google 的扩展签名。

上传前不要只靠 `1.0.0` 文件名或修改时间判断。以后重新构建后，请从项目 `release/` 取最新 ZIP；本次输出目录中的副本是本次交付时的快照。
