# JSON 工具箱：Chrome 商店发布资料

准备日期：2026-10-07。发布名称已确认为「JSON 工具箱」，与 `public/manifest.json` 一致，联系邮箱已由发布者确认可公开。以下内容对应本次 1.0.0 本地版。

## 现在的操作顺序

1. 在项目根目录运行 `npm run verify-package`。如果失败，先运行 `npm run package` 再验证。
2. 在开发者后台的“内容”页点击“上传新内容”，选择 `release/json-tool-extension-1.0.0.zip`。输出目录中提供了同一份安装包副本。
3. 完成下列商店资料、隐私权实践和分发设置，上传 `assets/` 内图片。
4. 将 `privacy-policy.html` 放到可公开访问、无需登录的 HTTPS 页面，确认实际 URL 能正常打开，再填进后台隐私政策字段。当前只有本地 HTML 文件，尚无已部署的隐私政策 URL。
5. 确认账号的邮箱验证、两步验证与 Trader／Non-Trader 声明已完成，且符合实际情况。
6. 首次发布建议选择“审核通过后手动发布”，核对资料后再正式发布。

## 详细介绍：可直接复制

```text
JSON 工具箱是一款在浏览器中运行的 JSON 编辑与处理扩展。点击浏览器工具栏图标，即可在独立标签页中打开双栏编辑器，编辑输入并预览处理结果。

主要功能
• JSON / JSON5 格式化、压缩、语法检查、转义与去转义。
• 保留长整数和高精度数值的数字字面量，便于查看订单号、ID 和精确数值。
• JSON 字典排序、字段排序和数据脱敏。
• Diff 对比，查看行级和行内差异。
• YAML、TOML、XML、Go、TypeScript 和 Cookie 格式转换。
• 本地文件导入、拖放、复制、结果下载和本地存档。
• 明暗主题、中英文切换，以及大文件折叠和层级分析。

本地运行与隐私
JSON 处理在您的浏览器内完成，处理脚本和编辑器均随扩展打包，不依赖在线后台。扩展不读取其他网页或浏览历史，不将您的输入、文件、草稿和存档上传给开发者或第三方。设置和存档保存在当前浏览器的扩展存储中。

使用方法
1. 安装后将“JSON 工具箱”固定到浏览器工具栏。
2. 点击扩展图标，在新标签页打开工具。
3. 粘贴 JSON 或导入本地文件，选择格式化、压缩、对比或转换等操作。

适用于桌面 Chrome 120 及以上版本。为了显示完整双栏编辑器，请使用宽度至少 901px 的浏览器窗口。存档与网站版本相互独立，重要内容建议导出备份。

支持与隐私问题：bing.devsec@gmail.com
```

## 如何确认安装包是最新的

`npm run package` 先构建当前源码，再生成 ZIP。ZIP 内的 `build-info.json` 记录 UTC 构建时间、Git 提交、是否含未提交修改及运行源码指纹；`release/` 同时生成 `.build-info.json` 与 `.zip.sha256`。

`npm run verify-package` 会核对当前版本与名称、源码和锁定文件的 SHA-256，以及 ZIP 的完整性。源码变更或 ZIP 被替换后会失败。文档与商店图片不影响运行，不纳入源码指纹。校验值用于核对本地构建，不代替 Google 的扩展签名。

上传前不要只靠 `1.0.0` 文件名或修改时间判断。以后重新构建后，请从项目 `release/` 取最新 ZIP；本次输出目录中的副本是本次交付时的快照。
